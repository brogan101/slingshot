# SlingShot IT Security Toolkit

**SlingShot** is an all-in-one IT security and system management toolkit built with Python, leveraging `tkinter` and `customtkinter` for a modern, user-friendly GUI. Designed for security professionals, system administrators, and IT enthusiasts, SlingShot provides a wide array of tools organized into categories like Security, Monitoring, Utility, Network, Backup, Advanced, IT Support, and Reconnaissance.

## Features

- **Comprehensive Toolset**: Over 150 tools for encryption, monitoring, network analysis, backup management, and more.
- **Custom Tool Integration**: Add your own scripts (Batch or PowerShell) seamlessly into the toolkit.
- **Real-Time Analytics**: Monitor CPU, memory, and disk usage with live graphs.
- **Task Automation**: Schedule tasks and manage system resources efficiently.
- **Dark Mode UI**: A sleek, customizable interface with dynamic resizing for optimal usability.
